IQBAL DAILY ACTIVITY CRM - install on Android

1. Go to https://app.netlify.com/drop (free) and drag this whole folder (or the ZIP) onto the page.
2. Netlify gives you an https link. Open that link in Chrome on your phone.
3. Tap the 3-dot menu > "Install app" (or "Add to Home screen").
4. Open the app once with internet; after that it also works offline.

Notes: data is stored on the phone. Use Backup / Download Excel regularly.
Reminders show while the app is open. Use the calendar button on an entry for alarms when closed.
